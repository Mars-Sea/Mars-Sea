## 🚀 代表项目

> <br />`TypeScript` · 已发布 npm 包 · 持续迭代中

**[doc-gen-service](https://github.com/Mars-Sea/doc-gen-service)** &nbsp;·&nbsp; ![stars](https://img.shields.io/github/stars/Mars-Sea/doc-gen-service?style=flat-square&label=%E2%98%85&color=2E9EF7)

> 基于 Spring Boot + poi-tl 的文档生成微服务，提供 REST 接口把结构化数据渲染成 Word / PDF 文档。
> <br />`Java` · `Spring Boot` · 模板化文档引擎

**[pot-app-translate-plugin-mtranserver](https://github.com/Mars-Sea/pot-app-translate-plugin-mtranserver)** &nbsp;·&nbsp; **[bergarust](https://github.com/Mars-Sea/pot-app-translate-plugin-bergarust)** &nbsp;·&nbsp; ![stars](https://img.shields.io/github/stars/Mars-Sea/pot-app-translate-plugin-mtranserver?style=flat-square&label=%E2%98%85&color=2E9EF7)

> <br />`JavaScript` · 离线 / 自托管 · 隐私友好

**[dsh-deeppilot](https://github.com/Mars-Sea/dsh-deeppilot)** &nbsp;·&nbsp; **[base64-text-converter](https://github.com/Mars-Sea/base64-text-converter)** &nbsp;·&nbsp; **[esp8266-desk-display](https://github.com/Mars-Sea/esp8266-desk-display)**
